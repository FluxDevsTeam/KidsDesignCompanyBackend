# Kids Design Company Backend

This is the backend for the Kids Design Company project. It provides APIs and services to support the frontend application.

## Features

- User authentication and authorization
- Product management
- Order processing
- Payment integration
- Email notifications
- Admin dashboard

## Technologies

- Python
- Django
- PostgreSQL


## Installation

To install the project dependencies, run the following command:

```bash
pip install -r requirements.txt
```

## Usage

To start the development server, run:

```bash
python manage.py runserver
```
